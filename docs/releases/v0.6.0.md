# Coworker v0.6.0

Chat with your coworkers from Discord, with threaded conversations, file delivery, and approvals. Discord and Telegram can stay connected to the same coworker at the same time.

## Discord support

- Connect a Discord bot and choose its coworker under **Settings → Integrations → Discord bot**.
- Invite the bot to your server and post the pairing code in the channel or thread you want to use.
- Mention the bot in a paired channel to start a conversation thread. Existing Discord threads keep their own conversations in Coworker.
- Send messages, images, and files to your coworker. Replies, file delivery, typing indicators, and 👀 receipts keep you informed in Discord.
- Approve or reject consequential actions from Discord, including proposed memory updates.
- Manage the integration from the CLI with `discord status`, `discord configure`, `discord unpair`, and `discord disconnect`.

## Delivery stays in the right place

- Requests now include their incoming channel in the model's context, including after approval pauses and task recovery.
- Messaging skills interpret “send it to me” or “send it here” using that channel. An explicit destination still takes precedence.
- Connecting Telegram and Discord to the same coworker does not make either service the default for requests arriving through the other.

## Reliability and upgrading

- Improved Discord reconnection, session cleanup, pairing detection, and approval-message updates.
- Existing Telegram connections remain available. Configure Discord separately after upgrading; a Discord bot token and server pairing are required.
- Enable the bot's Message Content Intent in Discord's developer settings so it can read messages.
