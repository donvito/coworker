# Coworker v0.7.2

Browse coworker files, choose where deliverables are saved, and keep conversations intact while switching between coworkers.

## Files and output folders

- Open **Files** beside **History** and **New** to browse the workspace and granted folders in a tree, or choose **All files** to search across locations.
- Preview, open, reveal, and download files. Select files or folders to download a ZIP to the location you choose.
- Grant each folder read-only or read-and-write access, and choose a default output folder. Document and invoice exports use that folder unless another destination is specified.
- The Files sidebar shows accessible folders, their permissions, and the default output destination. Collapse the folder list or click a folder to browse it.
- File deletion requires confirmation and moves files to Trash or Recycle Bin. Folder deletion has a separate warning: all contents are permanently deleted and cannot be recovered.
- Deleted tool-result cards lose their Open and Download buttons. Files removed outside the app show **File missing** when returning to the app; restoring them restores their actions.

## More file capabilities

- A bundled file-archiving skill creates ZIP deliverables.
- Document authoring supports HTML, JSON, and TSV through packaged scripts, alongside PDF, Word, Excel, CSV, and PowerPoint.
- Packaged skill scripts run in a controlled sandbox with folder permissions, execution limits, and artifact registration.

## Conversation and interface fixes

- Live replies and activity remain available when switching coworkers, including runs waiting for approval.
- Coworkers without a configured model show a clear notice instead of producing mock responses.
- Coworker roles appear below names in the left sidebar, and model-configuration notices wrap without being cut off.
- Folder access controls are more compact, and file deletion updates the explorer in place.
- Centered time and date displays appear on Home and above the coworker sidebar, with the sidebar toggle beside the clock.
- Windows file-path checks and Recycle Bin labels are consistent across the explorer and its confirmation dialogs.
